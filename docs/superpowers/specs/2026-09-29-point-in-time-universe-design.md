# 点时股票池数据建设

## 目的

为 A/B/C 趋势规则提供不含生存者偏差的历史回测股票池。没有点时成分数据时，回测必须保持 `INSUFFICIENT`，不得输出收益排名。

## 建议文件

`data/market/hs300_constituents_history.csv`

字段：

| 字段 | 含义 |
|---|---|
| `effective_date` | 成分生效日 |
| `end_date` | 成分失效日，未知时为空 |
| `code` | 六位证券代码 |
| `name` | 当时名称快照 |
| `source` | 数据来源 |
| `source_date` | 来源披露日期 |

同一股票的区间不得重叠；每个区间必须有来源标记。回测在交易日 `t` 只允许使用 `effective_date <= t < end_date` 的股票。

## 准入条件

1. 至少覆盖回测区间的起止日期；
2. 每次成分调整前后均有快照或明确生效区间；
3. 代码格式统一为六位数字；
4. 区间无重叠、无反向日期、无重复记录；
5. 与基准价格和财务公告可用日分别校验，不能用文件修改时间代替来源日期。

## 风险与代价

补齐历史成分股需要可靠的历史来源和人工抽样核对；来源不稳定时，宁可缩短可验证区间，也不能用当前成分股回填过去。数据建设完成后，旧的 +79% 趋势回测结论需要重新标记为“当前股票池回看历史”，不能与新结果直接拼接。
