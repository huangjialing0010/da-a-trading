# 变更记录

记录规则与架构的重要变更（日期倒序）。git log 保留完整过程，本文件是跨会话交接依据。

## 2026-08-11
- 新增可审计的重大业绩事件覆盖层 `data/market/earnings_alerts.json`：人工/AI核实后登记 `BLOCK/WARN` 事件。`BLOCK` 会在深价候选生成、候选缓存读取、结构化首仓风控和次日既有深价买单执行四处失败关闭；原始候选 CSV 保留审计快照，日报和追踪消费有效视图。卖单、已有持仓和冻结的趋势 V2 不受影响，事件必须显式复核关闭，禁止按日期静默过期。
- 首条覆盖事件为赛力斯（601127）2026 年半年度业绩预亏：候选池使用的一季报盈利信号已过时，深价结论由观望改为淘汰。
- 日报新增置顶“晨间执行卡”，集中显示数据截止日、深价/趋势 V2 账户浮盈亏金额、次日待执行订单及待分析股票；深价研究优先、趋势研究明确只作增强观察。
- 深价仓和趋势 V2 持仓表新增明确仓别、浮盈亏金额、盈亏率与本轮持仓时间。持仓时间从交易流水重建当前一轮首次建仓日，后续加仓不重置；流水缺失或异常时显示“未知”，不猜测日期。
- 此次仅调整报告呈现，不改变选股、仓位、T+1、止盈止损或趋势 V2 冻结参数。

## 2026-08-07
- 修复拆股/送转导致的深价伪跌幅：主备个股日K数据源统一为前复权 `qfq`，缓存键加入复权口径以隔离旧版未复权缓存；52周跌幅、价格分位、MA200和移动止盈共享一致价格序列，策略阈值不变。
- 实施普通深价最小自动首仓闭环：研究文件顶部的结构化 `BUY` 建议经候选资格、有效期、行情日期、建议区间、ERP/总仓位、单票、现金和行业集中度校验后，单日最多生成两张 T+1 虚拟订单；有效期内可消费前一交易日异步研究，次日开盘超出建议区间即取消。旧研究默认不可执行，趋势 V2 不受影响。
- 完成 P0 运行可靠性收口：CLI 保留控制台编码并替换不可编码字符，避免 GBK 因 emoji 中断；待研究提示改为准确的独立 AI/人工队列；深价自动订单按股票、订单类型、批次号和信号日做语义幂等，终结订单不得同日复活。
- 完成首次受控趋势 V2 日更：账户以 200 万元空仓建立，当日无成交；保留中国东航、厦门钨业两张 `2026-08-10` 虚拟待买订单。深价仓因持仓行情仅到 `2026-08-06` 而熔断，未写入交易或表现。
- 修复同一信号日重跑可追加不同趋势买单的问题：订单批次一旦形成，当日重跑不得扩充；重复运行产生的两张追加单保留审计记录并标记 `CANCELED`。
- 修复趋势周报空账户首次生成时的 `pandas` 局部变量错误，以及候选追踪 CSV 读写丢失股票代码前导零的问题。
- 日报把 `V2 明日执行清单（原策略）` 与 `增强研究观察（不影响趋势 V2）` 分开；研究建议不再显示为未标明口径的 V2 买入建议。趋势 V2 参数、候选和订单规则未改变。
- 完整五问与前瞻分组追踪暂缓；普通深价新开仓先采用最小结构化建议协议，趋势两问不改变趋势 V2。
- 自动交易执行口径改为 T+1：深价分批加仓、恐慌买卖、自动退出以及趋势买卖均在 T 日收盘生成订单，下一明确交易日开盘模拟成交；订单状态为 PENDING/BLOCKED/FILLED/CANCELED，带幂等标识和崩溃对账。
- 买单固定数量并预留估算资金；计划日一字涨停、确认停牌/无交易或跳空后资金不足即取消，不缩量。卖单按最终剩余持仓清仓，一字跌停/停牌持续重试；卖单优先但不得把同开盘卖出款用于买单。
- 趋势验证启用 `account_trend_v2.json` 200 万空仓账户，独立交易/表现/订单/冷却文件；旧 `account_trend.json` 及其历史输出只读保留。当前合仓报告切换为深价仓 + 趋势 V2，终审日取 2027-01-01 与 V2 启动满6个月的较晚者。
- 日报新增今日成交、待执行订单、阻塞/取消和旧趋势仓只读快照；自动策略状态只在真实模拟成交后推进，不再出现挂单失败但批次已前进。
- 加固虚拟盘 Actions 日更：依赖固定到 `requirements.txt`，日更前运行全量测试，串行化账户写入；缓存从整个 `data/` 缩小为非权威的 `financials/` 与 `sw_index/`，不再用旧缓存回填 `data/market/`，并移除无效的 `github.run_date`。
- 新增绝对交易日熔断：交易日历按 Asia/Shanghai 16:30 推导期望完整交易日，深价仓与趋势仓分别核对全部持仓；基准过期只冻结表现写入。
- ERP 仓位闸门由异常静默放行改为 fail-safe：异常时按项目既有 30% 保守上限判断并在日报显示降级原因。
- 修复股票池口径漂移：`stock_universe.csv` 只接受 250–350 只且全部标记“沪深300”的缓存，网络失败仅使用最后有效缓存，不再把全市场股票写成正式母集。
- 修复趋势候选结构性归零：保持 5–500pp、ROE≥6%、当前利润同比≥-20% 阈值不变，改为前置过滤后再取 TOP10。修复切点前的趋势候选来自错误的“全市场代码前300只”，不可与修复后样本混为同一口径。
- 修复趋势日报盘前/盘后时点混用：熔断仍使用盘前持仓，正常交易完成后从最终账户重建持仓表，当日新买入立即显示、已卖出不再列为持仓。
- 新增纯虚拟盘有效验证仪表板：保留历史账户，从 2026-08-07 单独统计有效完整回合、收益、超额和回撤；最早 2027-01-01 且四项门槛同时满足才显示“可讨论50万元小额实盘”，系统仍不连接券商。趋势周报改到趋势日更后生成，避免漏记当天交易。
