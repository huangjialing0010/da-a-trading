# 变更记录

记录规则与架构的重要变更（日期倒序）。git log 保留完整过程，本文件是跨会话交接依据。

## 2026-08-04
- 修复沪深300基准价自 2026-07-24 起冻结：`tools/auto_trader.py::_get_benchmark_price` 改用新浪 `stock_zh_index_daily` 为主、东方财富 `stock_zh_index_daily_em` 兜底；网络失败时打印告警并沿用缓存，不再静默失真。根因：东财接口持续 `RemoteDisconnected` 拒连。
- 落地治理规则（对抗式审查后）：
  - 趋势仓数据熔断：任一持仓K线最后日期早于基准缓存日期 → 当日买入/卖出均不执行、不记录净值/表现。
  - 深价仓超限处置：ERP 仓位上限与行业集中度只约束新增资金（含加仓），不强制减仓。
  - 终审样本不足顺延：2027-01-01 交易笔数 <30 时顺延 3 个月并附市场状态；≥30 时严格按原三条件执行。
- 新建 `output/market_judgment_log.md`：记录系统明确市场判断，每周五回填命中/未命中，作为系统可靠性度量。
- 环境事项：本地 `data/market/benchmark_000300.csv` 被 Excel 打开时会锁文件导致写入失败；关闭后重试，GitHub Actions 不受影响。
- 交易成本模型上线：`config.yaml` 新增 `costs` 段（佣金万2.5最低5元、卖出印花税0.05%、滑点0.1%）；`tools/account.py` 支持 `costs_enabled`，自动日更账户启用；一字板近似（开=高=低且方向不利）跳过成交。历史交易不追溯，回测基线保持无成本。
- 双策略组合总览上线：周报/月报新增「组合总览」，以深价 100万 + 趋势 200万初始资金权重合成合仓净值，输出累计收益/最大回撤/年化波动率/日收益相关度及近 10 交易日净值表；沪深300累计按基准缓存 close 计算（`performance*.csv` 中 7/24 起基准列沿用旧 4645.95，属历史口径）。
- 深价仓定位写回「左侧交易仓」（文档）：深价=左侧越跌越买、分批建仓，趋势=右侧趋势确认后追入。
