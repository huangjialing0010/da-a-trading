# 大A 虚拟盘交易系统

A股虚拟盘交易系统。不连接真实账户，所有交易在本地模拟；策略未验证前不上实盘。

## 双策略（双仓）

| | 深价仓 | 趋势虚拟仓 |
|------|----------|------------|
| 资金 | 100万（虚拟） | 200万（纸上测试） |
| 策略 | 左侧：跌40%+营收正增长+财务好，人工买入 | 右侧：利润趋势改善+质量过滤，自动执行 |
| 候选池 | `candidates.csv` | `trend_candidates.csv` |
| 状态 | 虚拟盘，ERP分位仓位+行业集中度约束，超限禁买 | V2 于2026-08-07空仓重启，最早2027-02-07审查 |

两仓均为虚拟账户：深价仓由人做最终买入决定，趋势仓自动执行仅供观察。

## 快速开始

```bash
python -m pip install -r requirements.txt

python main.py status   # 查看账户
python main.py daily    # 日更：价格刷新 + 信号检查 + 候选池 + 追踪 + 趋势虚拟仓
python main.py weekly   # 周报
python main.py monitor  # 持仓监控
```

CLI 会保留当前控制台编码，并把无法编码的 emoji 替换显示；Markdown 报告仍保留完整 UTF-8。Windows PowerShell 如需在终端完整显示 emoji，可额外设置 `$env:PYTHONIOENCODING='utf-8'`。

## 关键约定

- 不上实盘：趋势 V2 从 200 万空仓重新验证，审查日取“V2启动满6个月”和 2027-01-01 的较晚者；≥30个完整买卖回合、累计超额>0%、最大回撤>-50%才可讨论 50 万试点。旧趋势账户只读保留，不混入 V2 结果。
- 数据熔断：交易日历按北京时间16:30推导期望完整交易日；深价仓、趋势仓分别逐只核对持仓K线，异常只冻结对应仓的自动买卖和账户/表现写入。基准过期只冻结基准/超额表现，不阻断数据正常仓位的交易。持仓入场日从交易记录按单票重建，异常时跳过期限类退出但保留价格止损。
- 股票池：正式母集只接受经校验的沪深300成分缓存；网络失败仅使用最后有效缓存，不再降级为全市场。趋势候选先应用既有质量过滤，再按改善幅度取TOP10。
- T+1 模拟执行：自动路径在 T 日收盘生成订单，T+1 明确交易日开盘按 0.1% 不利滑点和费用成交；买单计划日无法成交或资金不足则取消，卖单一字跌停/停牌则持续重试。普通深价首仓只消费研究文件中的结构化 `BUY` 建议，单日最多两张，收盘或次日开盘超出建议区间均不成交。卖单优先，但同一开盘卖出款不能给买单补资金。`main.py trade` 手动记账仍为即时模拟成交。
- 重跑幂等：同一仓、同一方向、同一信号日形成订单批次后，当日重跑不得追加新标的；历史订单不删除，异常追加单以 `CANCELED` 保留审计。
- 报告口径：日报顶部“晨间执行卡”供次日开盘前快速查看数据状态、双仓浮盈亏金额、订单和待分析股票；持仓表逐票显示仓别、浮盈亏金额、盈亏率和持仓时间。持仓时间按当前一轮首次从零仓变为持仓的自然日计算，加仓不重置，流水异常显示“未知”。`V2 明日执行清单` 来自冻结的趋势原策略订单账本；`增强研究观察` 不生成或改变 V2 订单。研究建议不等于明日执行指令。
- 交易成本：纸面账户已计佣金（万2.5）、卖出印花税（0.05%）、滑点（0.1%）和一字板近似，参数在 `config.yaml` 的 `costs`。
- 市场判断台账：`output/market_judgment_log.md`，每周五回填命中/未命中，验证系统可靠性。
- 双策略组合总览：周报/月报按深价 100万 + 趋势 200万初始资金权重合成合仓净值，对比累计收益、最大回撤、年化波动率。
- 完整手册：`CLAUDE.md`（策略参数、开发约定、深度分析规范）；文档索引见 `docs/README.md`，变更记录见 `docs/CHANGES.md`。

## 退出规则

硬止损 -20%、MA200跌破+亏损>10%、移动止盈 +25%启动/-12%回撤、最大持有18月、基本面恶化（利润/营收同比-20%）。

## 自动化

GitHub Actions 工作日 17:30 自动执行日更，先跑全量测试，再执行虚拟盘日更并将结果提交回仓库。自动化只缓存非权威的财务与行业数据，不缓存账户、行情日线或 `data/market/`。

## 核心文件

- `config.yaml` — 所有策略阈值 + 回测结论
- `CLAUDE.md` — 开发约定 + 完整参数说明
- `docs/CHANGES.md` — 变更记录
- `tools/` — 核心模块
- `.github/workflows/daily.yml` — Actions 日更流水线
- `output/` — 账户、候选池、候选追踪、交易记录、表现追踪、周报/月报、市场判断台账、报告索引（`reports/README.md`）
