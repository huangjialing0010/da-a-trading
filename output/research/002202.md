## 业务驱动力

金风科技是中国最大的风力发电机组制造商，全球排名前三，成立于1998年，A+H两地上市。业务分为三大板块：

1. **风机及零部件销售**（主营，收入占比约65-70%）：销售风力发电机组，是波动最大、毛利率最低的板块
2. **风电场开发**（收入占比约15-20%）：自建风电场并网发电，收入稳定但依赖补贴
3. **风电服务**（收入占比约10-15%）：运维、技改、备件供应，增长稳定

### 核心驱动力链条

**政策装机目标** -> **运营商招标量** -> **金风中标份额** x **风机ASP** = 风机收入
**风资源/电价** -> **自营风场发电收入** + **服务合同积累** = 服务收入

2025-2026年收入大爆发（730亿/2025年，+28.8%；Q1 2026 155亿，+63.5%）来自：
- 十四五收官年抢装：2025年是十四五规划最后一年，风电装机大幅加速
- 大基地项目集中交付：沙戈荒风光大基地进入交货高峰期
- 风机大型化降本刺激需求：单机容量从3MW升至10MW+，单位千瓦成本骤降
- 订单储备足：金风在手订单超30GW，未来2-3年收入有保障

但收入增长的代价是毛利率崩塌，见下一节。

### 关键观察

**增收不增利 — 4年收入增43%，利润反降26%**。2021年营收509亿、净利37.3亿；2025年营收730亿（+43%）、净利仅27.7亿（-26%）。这是风电整机行业最核心的矛盾——市场份额争夺战摧毁了行业利润池。

**毛利率塌方**：从2021年22.55%降至2025年14.18%，四年塌陷8.4个百分点。原因：
- 风机投标价从2020年~4000元/kW暴跌至2025年~1500-1800元/kW，跌幅超55%
- 整机商为锁定份额不断让利给运营商
- Q1 2026毛利率16.76%较Q1 2025的21.78%进一步下滑5个百分点——短期反弹被证伪

**Q1 2026营收暴增+63.5%但毛利率反而下降**：卖了更多风机，但每台赚得更少。这是典型的"量升价跌"——收入增长由出货量驱动，ASP持续下行。

**ROE勉强及格**：7.08%（2025年），刚刚越过6%硬门槛。如果2026年全年毛利率继续下行（Q1趋势暗示如此），ROE有跌回6%以下的风险。

**资产负债率71.1%**，为候选池最高水平之一。74%负债率对于重资产制造业不算极端（可比公司明阳智能~65%，运达股份~80%），但结合7%的ROE来看——以71%的杠杆仅产出7%的ROE，资本效率极低。去杠杆后的真实资产回报率约2-3%。

**经营现金流质量尚可**：CFO/EPS=1.32，覆盖利润。但Q1 2026每股经营现金流为-0.37元，已转负。风电行业季节性特征明显（回款集中在Q4），但Q1转负需警惕应收账款增长。

**扣非与净利润吻合**（2025年扣非26.13亿 vs 净利润27.74亿，差异仅5.8%），利润质量尚好，不依赖一次性收益。

### 应收账款的隐雷

风电整机商的商业模式是：先垫资生产/交付，运营商分期付款，回款周期长达1-2年。应收账款周转天数从2022年的186天升至2025Q1的295天（翻倍）。金风的应收账款余额可能达300-400亿，在行业下行期，运营商拖欠和坏账是真实风险。

### 行业结构

### 竞争烈度：极高且持续恶化

**价格战**是最核心的竞争特征。整机商在争夺五大六小发电集团订单时主要靠价格取胜，技术差异不大。价格战逻辑如下：
- 下游客户（五大发电集团）高度集中，议价能力极强
- 风电整机技术趋同，差异化小，切换成本低
- 产能过剩：行业年产能超100GW，年需求仅60-80GW
- 三一重能以工程机械思维杀入，凭借成本控制进一步压低价格底线

**金风的"优势"**：
- 直驱永磁技术路线（无需齿轮箱，可靠性更高，运维成本低）——但这已被市场验证为成本更高、重量更大，并未带来定价权
- 市场份额第一，规模最大
- 在手订单充裕（30+GW），短期收入有保障
- 自营风场+服务收入提供稳定现金流（约占利润30%）

**金风的劣势**：
- 规模≠壁垒：大客户按年招标，每年重新洗牌，去年的份额不能保证今年
- 直驱路线的成本劣势：永磁体含稀土，成本受稀土价格波动影响大
- 海外拓展受阻：欧盟已对中国风机发起反补贴调查，出海战略面临贸易壁垒
- 服务收入虽稳定，但不足以抵消制造板块的利润下滑

### 护城河评估：无

风电整机是高度同质化的工业品。客户（发电集团）选择整机商的核心标准是**度电成本最低**——谁的整机每度电最便宜买谁的。不存在品牌忠诚、转换成本、网络效应或规模壁垒。技术路线差异（直驱vs双馈vs半直驱）不构成经济护城河，因为客户不关心技术路线，只关心度电成本。

**唯一的微弱优势**是金风在运风机保有量巨大（超100GW），服务合同有一定的更换成本和客户粘性。但服务收入占比不大（15%），无法支撑整体估值。

## 问题可逆性

### 核心问题分为两层：

**第一层：股价为什么跌？**（大概率可逆）

从37.03跌至16.69（-55%）的原因是主题泡沫破裂，不是基本面恶化。2025-2026年收入和利润都在改善。如果市场情绪修复，股价反弹至22-25（P/E 30-35x）是有可能的。

**第二层：商业模式的根本缺陷**（大概率不可逆）

风电整机行业价格战是结构性的，不是周期性的：
- 产品高度同质化 -> 不可能形成定价权
- 客户高度集中 -> 买方垄断压价
- 产能长期过剩 -> 供给端无法出清（有地方政府支撑，不会轻易退出）
- 技术趋同（直驱vs双馈差异缩小）-> 差异化越来越难
- 出海受阻 -> 新增量市场被封堵

毛利率从22.55%跌至14.18%，能不能回到20%+？极难。除非出现以下场景之一：
- 大量小厂出清（可能性低，有地方政府的产业政策兜底）
- 行业整合至CR3>70%（需要时间，且未必是金风吃掉别人）
- 技术跃迁形成差异化（目前看不到）

**结论**：股价从泡沫顶部回落是健康的，但回到"价值"区间不等于回到"低估"。当前P/E 28.8x（基于FY2025实际利润）对于一家7% ROE、71%杠杆、毛利率持续下滑的公司，仍然是昂贵的。

### 逆向思考 — 有没有可能看错了？

**看涨理由（我可能错在哪）**：
1. 十四五收官年抢装+十五五开局，2026年可能是装机大年，Q1的63.5%收入增速会延续
2. 风机价格可能已触底（1500元/kW以下低于全行业成本线），毛利率已见底
3. 如果2026年净利润达到35-40亿（基于Q1年化36亿+装机旺季），P/E降至18-20x，进入合理区
4. 自营风场转固完成后贡献稳定的发电收入，利润结构在改善
5. 国家电网加大投资、AI算力拉动用电需求、能源转型政策不断加码

**这些看涨理由的问题**：
- Q1毛利率16.76%同比Q1 2025的21.78%在下滑，价格底部的说法被数据否定
- 装机量增长可以推升收入，但如果毛利率继续下行，利润增长幅度远低于收入
- 即使2026年净利润35亿（比2025+26%），当前市值800亿PE=22.9x，仍不便宜
- 自营风场贡献的利润稳定性好，但体量不够大（每年贡献利润约5-8亿）

说明：
- **乐观假设**：毛利率止跌于14%，十五五抢装推动装机量再增20%+，全年净利润35亿。22x PE对应利润率稳定后的估值（但历史上稳定期也仅有10-15x）。
- **基准假设**：毛利率微降至13.5%，装机量稳定，全年净利润28亿。18x PE是A股制造业中等估值水平。对应目标价11.6元，距现价有37%下行空间。
- **悲观假设**：毛利率跌至12%以下，价格战恶化+应收账款减值，全年净利润22亿。12x PE对应"零增长+高负债"的困境估值。

**关键判断**：即使按乐观场景，当前18.37元也不具安全边际（目标价17.7，低于现价）。乐观假设下现价已充分定价。基准和悲观假设下存在显著下行风险。

### 为什么18x PE是基准而非25x？

风电整机行业缺乏可持续的竞争优势（无护城河），利润高度周期性。对于周期股且ROE仅7%的标的，15-20x PE是公允区间。2021年利润巅峰37亿时股价在16-18区间（当时PE~18x），可以作为估值锚。

## 买入理由

1. **量化指标初筛通过**：距高点跌50%+ROE 7%+CFO/EPS 1.32+利润+60%+营收+63%，满足深价策略所有硬性财务门槛
2. **收入爆发期**：进入十四五抢装+十五五开局，订单充裕（30+GW在手），短期收入有保障
3. **行业龙头地位**：中国风电整机市场第一，在运风机规模最大，服务业务有粘性
4. **泡沫已挤出大半**：P/E从58x（37.03高点）回落至29x，估值泡沫消化显著
5. **能源转型长逻辑**：风电在中国电力结构中占比将持续提升，2030年风光总装机目标1200GW，长期需求确定

## 不买理由

1. **商业模式有根本缺陷** — 这是最大的不买理由。风电整机是高度同质化的工业品，客户集中、切换成本低、长期价格战不可逆。毛利率从22.55%塌至14.18%，且Q1 2026继续下滑，无触底迹象。
2. **估值仍然昂贵**：29x P/E（基于FY2025利润）对于7% ROE、71%负债率、无护城河的周期股，即使在A股也偏贵。基准估值目标12元（18x PE），下行空间37%。
3. **"50%回撤"是虚假的安全感**：股价从10涨到37（+270%）之后再跌50%到18.37，回撤幅度看似大，但距52周低点仍涨84%。这不是超跌反弹机会，而是泡沫破裂后的中段。
4. **债务堰塞湖**：71.1%负债率，在候选池中最高。赚的钱都用于再投资（厂房、风场），自由现金流常年为负。2025年Q4突然出现正经营现金流0.84元/股，可能是一次性回款集中导致，不可线性外推。
5. **应收账款风险**：周转天数从186天升至295天，大量收入以应收账款形式存在。在行业下行期，坏账风险上升。
6. **新买入冻结**：ERP当前约3.87%，低于5%阈值。深价策略不允许新买入任何标的，此为硬约束，无需论证。
7. **竞争格局恶化而非改善**：三一重能持续扩产、远景能源未上市但融资能力强、行业产能过剩未见出清。价格战没有结束的信号。

## 决策

**结论：淘汰。不建议买入，也不列入观察名单。**

### 核心逻辑

金风科技通过了深价策略的全部量化筛选，但在深度分析层面暴露了不可忽视的商业模式缺陷：

1. **没有经济护城河**：产品高度同质化，客户只看度电成本，不存在品牌/转换成本/网络效应。风电整机是工业品，不是品牌消费品。
2. **毛利率趋势不可逆**：从22.55%跌至14.18%，Q1 2026还在继续下滑。这不是周期底部等反弹的问题——行业结构性的供过于求和客户集中度意味着毛利率大概率在10-15%区间成为新常态。
3. **估值不匹配风险**：29x P/E x 7% ROE = 2.03 P/E to ROE ratio。通常此比值>3意味着严重高估（1.5-2.5为合理区间）。金风需要ROE提升至12%+才配得上当前估值，而这在可见的未来不可能发生。
4. **泡沫后遗症**：1月300亿天量成交背后是巨大的套牢盘，技术面压力将持续压制反弹空间。

### 什么情况下可以重新考虑？

- 股价跌至12元以下（P/E<19x，接近基准目标价），且毛利率出现连续两个季度回升
- 行业出现明确整合信号（小厂退出/并购），竞争格局改善
- 公司ROE持续提升至10%+，同时负债率下降至60%以下
- ERP回到5%以上（解除新买入冻结）

以上条件至少需满足2-3条才值得重新评估。当前不满足任何一条。

### 与候选池其他标的的对比

同一个候选池中有大量比金风更优质的标的：
- 分众传媒（002027）：ROE 18.3%，负债率25.3%，梯媒垄断+强护城河
- 巨人网络（002558）：ROE 12.5%，负债率19.9%，利润+211%，游戏IP有复利
- 迈瑞医疗（300760）：ROE 21.6%，负债率24.8%，医疗器械龙头有技术和渠道壁垒

这些标的在估值水平相近的前提下，商业模式和资本回报率远优于金风科技。金风不存在"唯一选择必须买"的情况。
