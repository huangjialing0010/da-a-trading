# 厦门钨业 (600549) 深度分析

> 分析日期：2026-08-06
> 当前状态：深价候选（评分70.4）
> 行业分类：有色金属 / 小金属（申万二级2405）| 指数：沪深300

## 业务驱动力

厦门钨业是中国最大的钨产品供应商，全球钨产业链龙头。四大业务板块：

1. **钨钼**（核心，毛利贡献最大）：覆盖矿山开采-冶炼-硬质合金全产业链。中国控制全球约80%钨供给，公司矿山资源集中在福建。硬质合金用于切削工具、矿山工具、军工等，下游需求刚性较强。
2. **稀土**：南方稀土分离冶炼龙头，主要产品氧化镨钕等；2025年稀土价格底部回升，贡献业绩弹性。
3. **电池材料**：三元正极材料+钴酸锂，主要客户包括宁德时代等动力电池厂商。随新能源车渗透率提升持续扩产，2025年营收占比快速攀升是整体营收大增的主要驱动力。
4. **房地产**：逐步退出中，不再新增拿地，未来对利润影响递减。

护城河：钨资源稀缺性+全产业链整合+技术壁垒（硬质合金高端产品）。稀土分离产能有国家配额壁垒。

### 关键观察

**利润YoY +189% 的原因分析：不是低基数效应**

市场最初可能怀疑这是低基数导致的虚假增长（2025Q1利润偏低），但数据排除这一点：
- 2025Q1 扣非净利润 3.67亿，同比增长 +22%（vs 2024Q1的3.01亿）。2025Q1不是低谷，已经在上行轨道。
- 2026Q1 扣非净利润 10.97亿，同比增长 +198.64%，增速甚至高于报表净利润增速（+189.14%）。说明增长100%来自主营业务，**不是一次性收益**。
- 营收同步暴增 +87%（84.19亿 -> 157.43亿），量价齐升，不是单纯的利润率操纵。
- 真正的驱动：钨精矿价格上涨+电池材料大规模放量。2026Q1 钨精矿均价同比涨幅估计在30-50%，电池材料出货量可能翻倍。

但判断业绩持续性需要非常谨慎——2025年全年利润23.09亿中Q1仅占16.6%，Q3是传统旺季。如果2026年\"Q1等于半个往年全年\"的节奏能持续，全年利润可能50亿+；但如果钨价在2026Q2已见顶、电池材料利润率被压缩（行业通病），下半年可能大幅回落。

**营收趋势**：2022年因大宗商品牛市冲到482亿后，2023-2024年回落至354-394亿（价格回落+地产出清）。2025年回升至463亿，2026Q1单季跳至157亿。这是典型大宗商品周期股的营收形态——大起大落。

**CFO/EPS = 1.29（2025年报）的陷阱**：这个数字基于2025年报（OCF/股 1.87 / EPS 1.4546），看起来健康。但**2026Q1经营现金流每股为 -1.62**！利润大爆发的季度现金反而在大幅流出。可能原因：
- 收入翻倍 -> 应收账款/存货同步激增 -> 占用大量营运资金
- 电池材料业务通常账期长、回款慢
- 如果Q2现金流仍为负，这是利润质量的严重警报——需要2026年中报验证

**负债率55.6%**：对于有色金属矿业+冶炼企业不算异常（行业重资产属性）。但结合以下因素构成风险组合：
1. 2026Q1负经营现金流
2. 2024年底发生过资本运作（每股资本公积从2.33跳升至4.18，股本不变，推测为定增或资产注入）
3. 短期偿债能力偏紧：流动比率1.27（2026Q1），速动比率0.55

## 竞争格局

- **钨行业**：厦门钨业+中钨高新双寡头，公司在上游矿端和下游硬质合金均有布局，全产业链竞争力国内最强。全球范围与Sandvik、Kennametal竞争高端市场。
- **稀土**：六大集团格局已定，公司属南方稀土体系，资源储量不及北方稀土但冶炼分离技术领先。
- **电池材料**：竞争极度激烈，当升科技、容百科技、长远锂科等同业产能严重过剩。2025年行业加工费持续下压，公司优势在钨+钴酸锂协同而非纯三元竞争。

## 管理层行为

- 2024年底存在资本运作（每股资本公积从2.33升至4.18，推测定向增发或资产注入），目的可能是为电池材料扩产融资。
- 无重大增减持公告（公开信息层面）。
- 分红历史一般：周期股典型特征——利润大年分红、利润小年不分。
- 房地产业务退出策略在执行中，方向正确但进度取决于项目去化。

## 问题可逆性

**股价为什么从96.85跌到45.00（-53.5%，仅5周时间）？**

完整走势复盘：
- 2025年7月股价约20元，随后钨价+稀土价格启动，股价一路上行
- 2026年3月触及82元（第一波）：钨价持续攀升+2025年报发布确认利润大增
- 2026年5月回调至50元区间（第一波出货）：获利盘抛售，钨价出现松动
- 2026年6月从53元暴力拉升至96.85元（6月23日见顶）：**极可能是游资+散户追涨的投机性冲顶**——12个交易日接近翻倍，成交量暴增至1.67亿股/日（平时3-5千万），换手率超10%
- 2026年6月23日起断崖式下跌，27个交易日跌至45元（7月30日最低44.25）：缩量跌 -> 放量跌 -> 恐慌跌，无明显有效反弹

**下跌原因判断**：
1. **钨价见顶回落是主因**。作为强周期品种，股价先于商品价格见顶是常态。6月的暴力拉升本身就是见顶信号——乐观情绪极致释放后的反转。
2. **电池材料利润率担忧**。2026Q1虽然业绩好，但市场可能预期后续季度利润率承压（原材料涨价传导滞后、下游车厂压价）。
3. **获利盘集中出逃**。股价从20涨到97（+385%），低成本筹码在狂热中集中变现。
4. **市场风格切换**：7月A股整体调整，周期股/资源股遭到系统性抛售。

**问题能否自行修复？**
- 如果是单纯的获利盘出清+情绪修复，跌到位后会自然企稳——但目前日换手率仍有3%+，未见缩量筑底信号
- 但如果钨价真的进入下行周期（2026H2需求减弱+供给恢复），利润将大幅回撤。当前看似便宜的估值（PE 13-16x）会因利润崩塌而变得昂贵（周期股利润高点PE低才是陷阱）
- **核心不确定性：钨价现在是短暂回调还是周期拐点？这超出财务分析能力范围**

## 买入理由

钨资源全球稀缺+中国控盘供给，公司全产业链壁垒清晰。2026Q1利润爆发不是低基数幻觉而是真实量价齐升，若全年利润50亿+则当前PE仅14倍，相比历史水平和A股有色板块均值（20-25x）明显低估。股价腰斩提供了深度价值的入场窗口。

## 不买理由

Q1经营现金流-1.62/股与利润大增严重背离——利润是纸面的、现金是真实流出的。55.6%负债率+负经营现金流组合下，若钨价拐头、营收回落，公司面临双重压力。股价5周腰斩不是市场疯了——48个交易日从20到97的5倍涨幅和随后的A字杀，历史上往往意味着\"有些资金在顶部知道我们不知道的事\"。大宗商品周期不可预测，2026Q1有可能是本轮利润的绝对顶峰——买在利润最高点的周期股是价值投资最大的陷阱之一。

## 结论

- **建议**: 观望
- **关键理由**:
  1. 利润暴增的真实性（非低基数+扣非增速>报表增速）确认，但2026Q1负经营现金流使利润质量存疑。必须等2026中报（预计8月底前）验证：如果OCF转正、利润继续强势，再评估买入；如果OCF继续为负或利润环比大幅回落，则为淘汰。
  2. 股价从96.85直坠至45是典型的周期股\"A字杀\"——急涨急跌、换手率10%+的交易日密集出现。跌得快不代表跌到位，周期股底部的形成需要缩量横盘，当前日换手率仍有3%以上，未见筑底迹象。
  3. 钨价方向是最大变量——但这是商品研究范畴，不是财务报表能回答的。在大宗商品方向不明的窗口买入深度下跌的周期股，本质是赌商品价格反弹，而非价值投资。
  4. 如果在8月底中报前就必须做买入/淘汰决定：淘汰。深价策略要求买\"问题可逆+财务健康的便宜货\"，厦门钨业目前三者均不满足确定性标准——问题可逆性存疑（钨价方向未知）、财务有瑕疵（负OCF+高负债）、暴跌后估值是否真便宜取决于未来利润能否维持。
