## 业务驱动力

资源型多元金属集团，利润弹性集中在铜钴板块：主力矿山资产为刚果金 TFM、KFM 铜钴矿，国内三道庄钼钨矿，另有澳洲铜金矿（NPM）、巴西铌磷业务和 IXM 金属贸易平台【均待核实】。2025-2026 利润大幅增长的主要驱动是铜钴量价齐升：铜产量创新高、钴价受刚果金出口配额政策影响大幅上行【待核实】。贸易板块（IXM）贡献收入体量大但毛利率低，利润占比有限【待核实】。

**本股利润本质是商品价格 x 产量**，而非产品结构或份额的结构性改善——这决定了所有财务数字都必须放在周期语境下解读。

## 增长质量

- 营收同比 **+42.8%**、净利润同比 **+86.3%**、扣非净利润同比 **+78.9%**（口径均为 2026-06-30 报告期）。扣非与净利增速接近，说明利润增长非一次性收益驱动，含金量在同业中不算差。
- 每股经营现金流 0.97 元（2025-12-31 年报），现金流/收益比 **1.02**（>0.8 健康），利润有现金流支撑，非纸面利润。
- ROE **26.6%**、销售净利率 11.6%（均为 2025-12-31 年报口径）。资源+贸易混合结构下属正常水平。
- **但增长来源是商品价格**：营收 +42.8% 与净利 +86.3% 的弹性远超产量增速可解释范围，价格贡献为主【待核实：量价拆分】。财报滞后于商品价格——2026H1 的高增长反映的是此前铜钴价格上行期的成果，不构成对未来报告期的保证。

## 改善来源分类（参考项，深价候选非必填）

**商品或行业周期顶**。判断依据：净利 +86.3% 的弹性主要来自铜钴价格上行（而非产量或份额），且 52 周高点 28.23 回撤 -40.7% 提示市场已在定价周期回落【价格驱动待核实】。本分类不改变任何订单，仅供人工闸门从严输入与终审归因。

## 竞争格局

- 全球铜钴头部供应商，钴供应高度集中于刚果金（洛阳钼业与嘉能可主导全球钴供给）【待核实】。
- 钴价受刚果金出口配额政策直接干预，价格形成机制非完全市场化——政策转向是最大的单一风险源【待核实】。
- 铜行业长期供给受限（矿山品位下降、资本开支不足），需求端有电气化支撑【待核实】。

## 问题可逆性

核心问题不是经营恶化，而是**周期位置不可判定**：简报明确"商品周期：所属行业无对应商品映射，跳过检测"（MISSING）。铜钴价格当前位置与分位无法用本地数据核实，导致无法区分两种情形：

1. **铜钴价格已从顶部回落** → 利润见顶不可逆，未来 2 个报告期（三季报、年报）利润同比大概率恶化，财报高增长是后视镜；"跌 40%"是周期回落中段而非起点。
2. **铜价仍处高位、回撤主因是市场风格/情绪** → 存在均值回归空间，深价逻辑成立。

另有一项独立风险：若刚果金钴出口配额放松，钴价可能快速回落，直接冲击利润【待核实】。按 README 规则，该项与铜钴价格分位并列最高优先级外部核实项。

## 买入理由一句话

跌幅 -40.7% 达深价线，2026H1 营收 +42.8%/净利 +86.3% 且扣非同步、现金流/收益比 1.02、ROE 26.6%，是池内少见的"深跌 + 强财务"组合。

## 不买理由一句话

利润弹性来自铜钴价格周期而商品周期分位 MISSING 无法核实位置，PB 约 4.0 倍（由简报 16.75/4.19 计算）对资源股不算便宜，现价低于 MA200 达 -13.4% 下行趋势未扭转，且财报高增长滞后于商品价格、未来报告期存在恶化风险。

## 结论：观望

结论依据（逐条对应简报数字与定性分析）：

1. **深价初筛全过**：距高点跌幅 -40.7%（≥40% 达标）、ROE 26.6%（≥6% 达标）、营收同比 +42.8%（≥0 达标）、净利同比 +86.3%（≥-20% 达标）、现金流/收益比 1.02（≥0.8 健康）。候选资格成立，不淘汰。
2. **但商品周期分位 MISSING**（简报原文："无对应商品映射，跳过检测"）：按 README 规则，强周期行业必须将周期/价格分位列最高优先级外部核实项。核实前无法确认"跌 40%"是均值回归起点还是周期回落中段——这是本股不能给出买入结论的直接原因。
3. **技术形态未企稳**：收盘 16.75 低于 MA200（19.35）达 -13.4%，量能 0.58 倍接近但未达明显缩量线（<0.5），左侧特征明确、无右侧信号。
4. **估值非深价**：PB 约 4.0 倍（16.75/4.19 计算）。周期股底部特征通常是 PB 回到 1-2 倍区间，当前 PB 更接近"周期利润尚在高位"的定价，印证财报滞后风险。
5. **等待验证节点**：三季报（披露日期待核实，约 2026 年 10 月下旬）若确认铜钴价格回落传导至利润同比拐点，则形态 1 坐实，应转向淘汰；若利润仍强且外部核实铜价分位不高，可升级为条件观察。
