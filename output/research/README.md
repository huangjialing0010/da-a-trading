# 深价研究文件约定

## 研究草稿（drafts/）

`output/research/drafts/` 存放 AI 生成的**未审核研究草稿**，配套 `{code}_brief.md` 为 `tools/research_brief.py` 产出的数据简报（草稿唯一数字来源）。

- 草稿不触发任何自动化：不生成订单、不写入 `progress.json`、不改候选文件；晋升（草稿 → `output/research/{code}.md` + 结论为 BUY 时补 YAML 头 + 登记 progress.json）一律由人工确认后执行。
- 草稿顶部不写 BUY YAML 头部；YAML 只在人工定稿且结论为 BUY 时按下方规则补填。
- 简报中 MISSING 的数字，草稿同样写 MISSING 并说明影响，禁止推测。
- 定性内容中可核查的具体事实（排名、产能、人事、并购时间）必须带 **【待核实】** 标记，并在文末"外部核实清单"汇总。
- 商品周期分位 >60% 时，草稿结论默认不为"买入"，除非论证本次周期结构不同。

## 趋势候选的改善来源分类与预注册归因（2026-09-30 新增）

趋势候选的研究（草稿与定稿）必须给出"改善来源分类"，固定五选一：**经营性量价驱动 / 低基数减亏 / 利润率扩张 / 投资收益或市场beta / 商品或行业周期顶**，并附一句判断依据。该分类不改变趋势 V2 的任何订单（V2 冻结不动），用途有二：

1. **人工闸门从严输入**：真钱（卫星仓）审核时，非经营性来源的候选默认从严处理。
2. **预注册归因**：V2 终审时按分类分组统计回合收益。若低基数/beta/周期顶类显著拖累，作为**终审后**策略改进的证据；纸上测试期间不得据此调参（中途调参=测试作废）。

商品周期映射表未覆盖的强周期行业（航运运价、金融投资收益等），简报按 MISSING 显式标注、禁止静默跳过；对应研究必须将周期/市场分位列为最高优先级外部核实项。

## 研究进度与条件观察

本目录可新增 `progress.json`，保存人工或独立研究任务完成后的记录；日更只读，不自动生成研究或订单。格式为 `{"reviews": [...]}`。每条包含六位 `code`、`reviewed_on`（YYYY-MM-DD）、`conclusion`（买入/条件观察/观望/淘汰/持有）、`next_check`。报告固定引用本目录 `{code}.md`，必须实际存在。同一周同一股票多次复核只计一次完成。禁止用文件修改时间回填历史。

只有 `conclusion` 为 `条件观察` 且额外填写 `valid_until`、正数 `price_min`/`price_max`、非空 `trigger`、`abandon_if` 的有效记录进入B级。这些字段是研究条件，不是自动买单；条件兑现后仍需完整买入审核。失效、未来日期、格式错误均不得显示为有效B级。记录按时间追加，最新复核取代该股票旧结论。示例仅供格式参考，不要直接作为推荐写入：

```json
{"reviews": [{"code": "600426", "reviewed_on": "2026-09-28", "conclusion": "观望", "next_check": "新财报披露后复核经营现金流"}]}
```

每周2只研究是待完成目标，缺记录表示未登记，不表示市场没有机会。历史正文仍保留，不强制改写。

普通研究正文继续使用既有七维度模板。只有明确建议普通深价虚拟仓首次买入时，才在 `output/research/{六位代码}.md` 文件最顶部增加以下 YAML；观望、淘汰和趋势观察不要填写可执行 `BUY` 头部。

```yaml
---
schema_version: 1
decision_id: DV-20260807-600426-01
code: "600426"
name: 华鲁恒升
strategy: deep_value
decision: BUY
signal_date: 2026-08-07
valid_until: 2026-08-10
buy_price_min: 19.50
buy_price_max: 21.50
quantity: 2000
abandon_if: 下一期营收转负，或经营现金流明显恶化
---
```

规则：

- `signal_date` 是研究建议形成日，不得晚于消费该建议的日更信号日。
- `valid_until` 必须覆盖计划成交日；日更可以消费仍在有效期内的前一交易日异步研究建议。
- `quantity` 必须为 100 股的正整数倍；系统不会因现金不足自动缩量。
- 当前收盘价和次日开盘价都必须在建议区间内。
- 系统还会检查候选资格、ERP/总仓位、单票上限、现金、行业集中度和数据新鲜度。
- 单日最多生成两张普通深价首仓订单；旧研究没有 YAML 时只作为研究资料，不会自动交易。
- 本系统只执行本地虚拟盘，不连接券商；结构化建议不代表保证盈利。
